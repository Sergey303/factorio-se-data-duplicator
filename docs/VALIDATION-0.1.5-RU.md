# SE Data Duplicator 0.1.5 — проверка перед публикацией

Эта редакция **сохраняет номер 0.1.5**, так как предыдущая сборка ещё не опубликована. Основание: установленный на игровом компьютере Space Exploration 0.7.64 и прототипы Factorio 2.1.

## Проверенная область

- В исходном `prototypes/phase-1/item/items.lua` обнаружено **81** допустимое название: 78 обычных карт и 3 вида данных зондов.
- Не включаются `se-significant-data`, `se-empty-data`, `se-junk-data`, `se-broken-data`.
- Источники трёх зондовых данных: `se-belt-probe-data`, `se-star-probe-data`, `se-void-probe-data` — `rocket_launch_products`; отдельного рецепта их изготовления нет.
- В `se-deep-catalogue-2` оригинальный SE открывает четыре вида данных: singularity, hyperlattice, timespace anomaly, annihilation.
- Наша механика копирования сохраняет температуру −100°C на входе и +25°C на выходе, 10 единиц жидкости и взаимно-исключающие результаты (по умолчанию 90% / 10%).

## Что исправлено в неопубликованной 0.1.5

1. Основной рецепт карты определяется строго по собственному имени и `main_product`. Промежуточные и побочные результаты чужих рецептов больше не привязывают копирование к их технологиям.
2. Рецепты карт, которых нет в эталоне SE 0.7.64, отключены по умолчанию. Можно включить исследовательский режим неизвестных карт, но без основного рецепта и технологии копирование всё равно не откроется.
3. Данные зондов по умолчанию не копируются. Настройка остаётся доступной.
4. Добавлен настраиваемый режим уровней суперкомпьютеров: обычные ветки науки 1–4 → машины I–IV; Deep Space 1–2 → III, 3–4 → IV.
5. Наложен отличительный графический символ двух карт на рецепты копирования.
6. Лишние эффекты разблокировки в дереве технологий скрываются через `hidden = true`, сохраняя оригинальные иконки SE.
7. Сведения о каждом из созданных рецептов выводятся в `factorio-current.log` в строках `MAP card=... source=... technologies=... min-computer=...`.
8. Если дополнительный рецепт нельзя безопасно построить из прототипов, он пропускается с предупреждением. Базовые несовместимости SE по-прежнему останавливают загрузку с точным названием отсутствующего прототипа.

## Проверки

- `tests/mock_test.lua` + `tests/run_mock_tests.py`: **56 сценариев**, все 81 оригинальное имя карт, проверки неизвестных данных, технологии побочного продукта, диапазоны 0%, 1%, 10%, 49%, 50%, 99%, 100%.
- `tools/audit_se_source.py`: независимо читает оригинальный ZIP SE 0.7.64, сравнивает 81 имя с `mod/known-cards.lua` и извлекает каталожные технологии в JSON. Не запускает игру и не меняет сохранения.
- `tests/check_package.py`: структура ZIP, мини-значок, лицензия, локализации, стартовые значения и все файлы.
- По настоящему игровому логу старой сборки были 81 рецепт и 3 запасные разблокировки. В новой версии 78 рецептов по умолчанию и 81 при ручном включении зондовых данных, если другие моды не изменяют базовые прототипы.

## Оставшиеся ограничения

- Статическое чтение исходных файлов SE **не равно** полноценному экспорту `data.raw` после всех 41 активных модов.
- Нет полной автоматизированной игровой проверки каждого суперкомпьютера, рецепта и существующих сохранений; нужна проверка запуска Factorio после установки собранного ZIP.
- В исходных технологиях могут появляться новые и альтернативные методы открытия карты: для них предусмотрены диагностика и режим осторожного пропуска, но не доказана совместимость с произвольными будущими версиями.
- Смена значения по умолчанию для данных зондов может не повлиять на уже сохранённую пользовательскую startup-настройку. Нужно проверить её в интерфейсе модов.

## Команды

```sh
python3 tests/run_mock_tests.py
python3 tools/package_mod.py
python3 tests/check_package.py

# На Windows, установлен SE 0.7.64:
python tools/audit_se_source.py --output "D:\projects\ChatPilotGroup\SE-Data-Duplicator-0.1.5-coverage.json"
```

Отчёт создаётся без изменения установленного Space Exploration.
